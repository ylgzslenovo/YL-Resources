# 资源文件夹 / Resources

这个文件夹用于存放 YL-Resources 的资源文件。

This folder is used to store resource files for YL-Resources.

## 说明 / About

- 这里由站长上传和整理个人研究资料、APK、研发成果与小工具。
- 访客可以通过 GitHub Issues 提交自己的作品，提交后由站长审核并整理到此文件夹。
- 请勿提交违法、侵权或恶意文件。

- The site owner uploads and organizes personal research materials, APKs, original work and small tools here.
- Visitors may submit their own work via GitHub Issues. Submitted work will be reviewed and organized into this folder by the site owner.
- Do not submit illegal, infringing or malicious files.

## 提交方式 / How to Submit

通过 GitHub Issues 提交作品：

https://github.com/ylgzslenovo/YL-Resources/issues

在 Issue 中说明：

- 作品名称 / Title
- 作品简介 / Description
- 文件链接或附件 / File link or attachment
- 作者署名 / Author name

Submit via GitHub Issues:

https://github.com/ylgzslenovo/YL-Resources/issues

Please include:

- Title
- Description
- File link or attachment
- Author name
